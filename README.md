## 📦 Itens da Avaliação

### Item 1 — Business Model Canvas (BMC)
* **Descrição:** Preenchimento dos 9 blocos do BMC de forma pragmática para o projeto proposto pelo grupo (Sistema de Gestão de Condomínio), estruturando a primeira versão da modelagem de negócios[cite: 2].

### Item 2 — Telas e Wireframes (Figma)
* **Descrição:** 
  * Identificação dos usuários do sistema (Síndico, Porteiro, Chefe de manutenção, Moradores, Visitantes)[cite: 2].
  * Elaboração de wireframes em baixa fidelidade no Figma[cite: 2].
  * Disponibilização de link público e acessível sem autenticação (testado rigorosamente em aba anônima)[cite: 2].

### Item 3 — Pesquisa Bibliográfica de POO
* **Descrição:** 
  * Pesquisa baseada nas referências oficiais do plano de ensino (como a bibliografia básica da disciplina)[cite: 2, 8].
  * Apresentação das definições dos pilares da POO (Encapsulamento, Herança, Polimorfismo e Abstração) sob o ponto de vista dos autores, incluindo citações literais[cite: 2, 8].
  * Levantamento e discussão em grupo de conceitos que geraram dúvidas para debater nas próximas aulas[cite: 2, 8].

### Item 4 — Lista de Exercícios em Java (`gestao-condominio`)
* **Descrição:** 
  * Implementação incremental de 20 exercícios em Java estruturados de forma progressiva (variáveis, leitura com `Scanner`, estruturas condicionais, laços de repetição, criação de classes, objetos, encapsulamento, herança, sobrescrita/sobrecarga de métodos e menus interativos de terminal)[cite: 2].
  * O código evolui de forma que o exercício seguinte substitui/refatora o anterior, resultando em um projeto completo entregue em formato `.zip` (`grupo_N_projeto.zip`)[cite: 2].
